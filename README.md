## 🎮 About

BGMI UNIVERSE is a multi-page gaming website based on the BGMI experience.

I built this project to bring different parts of the game together in one website, including weapons, vehicles, maps, skins, equipment, characters and esports.

The main idea was to focus on the visual side of the website along with responsive layouts, animations, interactive cards and multimedia content.

---

## ⚡ Sections

| Section | What it contains |
|---|---|
| 🏠 Home | Main landing page and featured content |
| 🔫 Weapons | Weapons and their visual details |
| 🚗 Vehicles | Different vehicles and related content |
| 🗺️ Maps | BGMI maps and map-based content |
| 👤 Characters | Character showcase |
| ⚙️ Equipment | Equipment and game-related items |
| 🎨 Skins | Skins and cosmetic content |
| 🏆 Esports | Esports and competitive content |

---

## ✨ Features

- Gaming-style dark interface
- Red, white and black visual theme
- Responsive layouts
- Animated sections
- Hover effects
- Interactive cards
- Background videos
- Image-based sections
- Custom CSS styling
- SVG graphics
- Separate pages for different sections

---

## 📱 Responsive Design

The website is made to work on different screen sizes, including:

- Desktop
- Laptop
- Tablet
- Mobile

The layout, cards, navigation and spacing adjust according to the screen size.
